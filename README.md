# Before the Name

**Art, AI, and Attribution** · Mark Terranova (MarkDude)

A postcard is offered. Someone looks, connects, reacts—or puts it down. From that modest encounter, this talk separates what a work is, whether it is good, whether we like it, and how it was produced.
